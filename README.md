# Supply-Chain-Analytics-Suite

Strategic supply chain decision-support engines utilizing advanced analytics for inventory optimization and logistics analysis.

## Executive Summary
This repository contains strategic decision-support tools designed to optimize inventory capital and logistics infrastructure for consumer electronics. These models move beyond basic reporting to provide dynamic simulations for safety stock, SKU classification, and margin-leak identification.

## Project: Electronics Supply Chain Decision Engine
* **Objective:** Developed a predictive framework to optimize inventory capital, shifting from static tracking to a dynamic, data-driven decision-support model.

### Key Techniques
1. **Pareto ABC Classification:** Isolated high-impact SKUs to prioritize capital allocation.
2. **Dynamic Modeling:** Automated reorder-point calculations accounting for demand volatility and lead-time variability.
3. **Strategic Insight:** Identified "Margin Leaks" to balance service levels with working capital efficiency.

## Data Sources
* The `Electronic_Sales.csv` dataset was sourced from **Marianela Baez** via Kaggle. This dataset is utilized for the sole purpose of demonstrating supply chain modeling and inventory optimization techniques.
